# Day 19 — Reference Sheet
*Keep — prevention builds walls; response is the fire drill.*

- **IR loop:** Prepare → Detect → Contain → Eradicate → Recover → Lessons Learned.
- **Detect:** logs (record) + IDS (wire) + **SIEM** (correlate → one incident). AI-SIEM = automated correlation/alerting.
- **Contain:** isolate the segment (the Day 12/17/18 fence) — limits blast radius.
- **Eradicate:** patch (D14) + fix code (D16) + close misconfig (D18).
- **Recover:** restore clean (Day 12 step 7).
- **Lessons Learned → Security by Design (Day 18).**
- Attack+defend seen from both chairs — the capstone flip.
