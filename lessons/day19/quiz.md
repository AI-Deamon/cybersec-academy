# Day 19 — Quiz (exit, 4 questions)
*Formative only — reinforces, doesn't punish.*

1. **Incident response primarily exists because:**
   a) Prevention always works
   b) Prevention reduces but never eliminates incidents — response limits damage
   c) Firewalls are illegal
   d) Logs are optional
   **Answer: b**

2. **The correct order of the IR lifecycle is:**
   a) Recover → Detect → Contain → Eradicate → Prepare
   b) Prepare → Detect → Contain → Eradicate → Recover → Lessons Learned
   c) Contain → Detect → Recover → Eradicate
   d) Detect → Recover → Prepare → Contain
   **Answer: b**

3. **Containment in IR is best described as:**
   a) Unplugging the entire network
   b) Surgically isolating the affected segment to stop spread (the Day 12/17/18 "fence")
   c) Deleting all logs
   d) Ignoring the incident
   **Answer: b**

4. **A SIEM's main value in detection is:**
   a) Replacing firewalls
   b) Correlating isolated signals across sources into one incident picture
   c) Writing code
   d) Encrypting traffic
   **Answer: b**

---

## Optional extension (discussion)
5. Why is "Lessons Learned" part of the IR loop, not an afterthought?
   **Model answer:** it feeds back into prevention (Security by Design, Day 18) — the incident reveals the preventable mistake, so the next iteration prevents it. The loop only improves if you close it.
