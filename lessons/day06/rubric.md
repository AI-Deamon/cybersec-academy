# Day 6 — Assessment Rubric
*Used by the instructor to assess the quiz + lab. Formative — guides improvement, not punishment.*

| Criterion | Excellent (3) | Adequate (2) | Needs work (1) |
|-----------|---------------|--------------|----------------|
| **OS concept** (quiz Q1) | Explains OS as referee between apps/hardware; names what it controls | Knows definition, vague on "what it controls" | Confused |
| **Analogy** (quiz Q2) | Maps shell→walkie-talkie; can map users/permissions too | Maps shell only | Can't |
| **Linux vs Windows** (quiz Q3) | States same concepts, different commands | Mixes up | Thinks one has no security model |
| **Privilege** (quiz Q4) | Explains privilege + why attackers want more | Knows "admin = power" | Can't explain |
| **Lab** (Tasks 1-3) | Ran whoami/pwd/ls on own machine; read-only; wrote reflection | Completed with minor help | Could not safely complete |

**Scoring guidance:** 12–15 = strong; 8–11 = on track; ≤7 = revisit before Day 7.
**Definition-of-Success check (ADD §13):** can the student explain the OS in their own words, run safe shell commands unaided, and state why privilege matters?
