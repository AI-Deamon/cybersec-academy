# Day 6 — Reference Sheet
*Keep this for the whole course.*

- **OS:** software between apps and hardware; enforces users, permissions, processes, files.
- **Analogy (unified, ONE for the whole academy):** Restaurant = Computer · Manager = OS · Chef = CPU · Kitchen counter = RAM · Pantry = Storage · Employees = Processes · Walkie-talkie = Shell · Key cabinet = Permissions. Users = identities; Employee on shift = Process. See `diagrams/os-signature.md`.
- **Linux vs Windows:** same concepts, different commands. Linux shell = **Bash**; Windows shell = **PowerShell / CMD**.
- **Shell basics:** `whoami` (identity) · `id` (Linux groups) · `pwd` (where am I) · `ls` / `dir` (list) · `cd` (change folder).
- **Privilege:** what a user may do. **Least privilege** = give only what's needed. Most breaches = gaining excess privilege.
- **Kernel:** the OS core that talks to hardware (the manager's brain).
