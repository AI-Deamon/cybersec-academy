# Day 1 — Quiz (exit, 4 questions)
*Formative only — reinforces, doesn't punish.*

1. **Which best defines ethical hacking?**
   a) Hacking without making money
   b) Security testing with permission, in scope, in writing
   c) Testing any public website
   d) Using open-source tools
   **Answer: b**

2. **Your friend says "just test my website, it's fine." Is that enough authorization?**
   a) Yes, verbal is fine
   b) No — get it in writing with clear scope
   c) Only if the site is small
   **Answer: b**

3. **Convert 'C' (ASCII 67) to 8-bit binary.**
   a) 01000011
   b) 01000010
   c) 11000011
   **Answer: a (64+2+1 = 67)**

4. **Hex `69` represents which character (ASCII)?**
   a) 'A'
   b) 'i'
   c) 'B'
   **Answer: b (105 decimal = 'i')**

---

## Optional extension (discussion)
5. In one sentence: how is the word "Hi" on disk (bytes `48 69`) the same kind of thing as malware, and what makes one safe and the other dangerous?
   **Model answer:** Both are just bytes; what differs is *authorization and intent* — whether you had permission to create/touch them and what they're used for.
