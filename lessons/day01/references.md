# Day 1 — Reference Sheet
*Keep this for the whole course.*

- **The Rule:** No permission = don't. Get authorization in writing with clear scope.
- **Bit:** 0 or 1. **Byte:** 8 bits (0–255). **Hex digit:** 0–F, represents 4 bits.
- **ASCII quick map:** A=65, B=66, C=67, … Z=90; a=97 … z=122; space=32.
- **Powers of two:** 128 64 32 16 8 4 2 1.
- **Commands:** `xxd file.txt` (Linux/Mac hex dump). Windows: HxD hex editor.
- **Encoding ≠ encryption.** Encoding = representation; encryption = hiding meaning.
- **Worked examples:**
  - "Hi" = `48 69` (hex) = `01001000 01101001` (binary).
  - 1 MB = 1,048,576 bytes = 8,388,608 bits.
  - 'é' (UTF-8) = 2 bytes `c3 a9`.
