# Day 1 — Assessment Rubric
*Used by the instructor to assess the quiz + lab. Formative — guides improvement, not punishment.*

| Criterion | Excellent (3) | Adequate (2) | Needs work (1) |
|-----------|---------------|--------------|----------------|
| **Ethics understanding** (quiz Q1–2) | Correctly distinguishes authorized vs illegal; cites "no permission = don't" | Knows the rule but fuzzy on why | Confuses public access with permission |
| **Binary conversion** (quiz Q3 / lab) | Converts a letter to correct 8-bit binary unprompted | Needs the ASCII table but gets it right | Errors in bit positions |
| **Hex/encoding link** (lab Task 3) | Reads hex bytes and maps to ASCII correctly | Maps with help | Cannot connect hex to characters |
| **Connections** (worksheet Q8) | Explains love-letter-vs-malware link with ethics insight | States both are bytes but weak on "what makes one dangerous" | No connection made |
| **Soft-skill (notes)** | Took structured notes using the taught method | Partial notes | No notes |

**Scoring guidance:** 12–15 = strong; 8–11 = on track; ≤7 = revisit concepts 1:1 before Day 2.
**Definition-of-Success check (ADD §13):** can the student explain bits *and* ethics in their own words, and perform the lab without step-by-step hand-holding?
