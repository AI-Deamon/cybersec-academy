# Day 9 — Quiz (exit, 4 questions)
*Formative only — reinforces, doesn't punish.*

1. **When you run `python script.py`, the OS:**
   a) Ignores permissions for scripts
   b) Creates a Process that runs as you and is checked by the same permissions
   c) Gives the script admin automatically
   d) Deletes the script after running
   **Answer: b**

2. **If you cannot open a file, your Python script:**
   a) Can still open it (scripts are special)
   b) Cannot open it either — same permission check
   c) Asks the OS to override
   d) Renames it
   **Answer: b**

3. **Why is Python useful in security?**
   a) It replaces the OS
   b) It automates observation/tasks (parse logs, check files) at scale
   c) It makes computers faster
   d) It encrypts the disk
   **Answer: b**

4. **A malicious script you run is dangerous because:**
   a) It runs with your privilege and can do what you can
   b) It cannot affect your files
   c) Scripts are always safe
   d) It only prints text
   **Answer: b**

## Optional extension (discussion)
5. Defenders script scans of thousands of files for weak permissions; attackers script too. What single habit keeps you safe?
   **Model answer:** run only code you understand (and keep to least privilege) — a script is you, automated, with your badge.
