# Day 3 — Assessment Rubric
*Used by the instructor to assess the quiz + lab. Formative — guides improvement, not punishment.*

| Criterion | Excellent (3) | Adequate (2) | Needs work (1) |
|-----------|---------------|--------------|----------------|
| **Network & packets** (quiz Q1) | Explains packets as addressed chunks; contrasts with "one blob" | Knows packet definition but vague | Confused |
| **Addresses** (quiz Q2–3) | Distinguishes IP (route) vs MAC (local ID) vs port (service) | Mixes up two of them | All three confused |
| **Security failures** (quiz Q4 / worksheet) | Names the 3 failures and maps HTTPS to eavesdropping | Names them but shaky on mapping | Can't name them |
| **Lab** (Tasks 1–3) | Found IP+MAC; pinged; described a hop as a router | Completed with minor help | Could not complete safely |
| **Connections** (curiosity/hw) | Explains envelope vs address insight (TLS seals contents, not dest) | Partial | No connection |

**Scoring guidance:** 12–15 = strong; 8–11 = on track; ≤7 = revisit concepts 1:1 before Day 4.
**Definition-of-Success check (ADD §13):** can the student explain a network in their own words, perform the lab without hand-holding, and name the 3 failures + which TLS fixes?
