This is the whole lesson's frame. Bash and Python are just two spellings of these 5 ideas. Don't teach "a language" — teach the 5 blocks, twice.

Gotchas to say out loud: NO spaces around `=`. `$var` to read, `var=` to set. `[ ... ]` needs spaces inside. `$(...)` is the modern command substitution. Exit codes: every command returns one; 0 = ok, non-zero = failed. Scripts chain on this.

The big Python gotcha: INDENTATION defines blocks (no braces, no `end`). 4 spaces. Mixing tabs/spaces = error. `f"...{x}..."` = f-string (formatting). `==` compares, `=` assigns. Don't teach classes/decorators/anything else. These 5 blocks + import.
